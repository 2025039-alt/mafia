# 한밤 마피아

마피아42 방식의 온라인 마피아 게임입니다. 방 코드로 모이고, 사회자는 AI가 맡습니다.
직업은 **마피아 · 경찰 · 의사 · 시민** 네 가지뿐입니다.

서버 없이 GitHub Pages만으로 돌아갑니다. 방장의 브라우저가 서버 역할을 하고, 참가자는 방장에게 직접 연결합니다(WebRTC, PeerJS 사용).

---

## 1. GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. 이름은 자유이고, 공개(Public)로 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 맨 위(루트)에 올립니다. (저장소 화면의 **Add file → Upload files**)
3. 저장소의 **Settings → Pages**로 들어갑니다.
4. **Build and deployment**에서 Source를 **Deploy from a branch**로 두고, Branch를 `main`, 폴더를 `/ (root)`로 고른 뒤 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면에 `https://내아이디.github.io/저장소이름/` 주소가 나타납니다. 이 주소를 친구들에게 보내면 누구나 접속할 수 있습니다.

비용은 들지 않습니다. 서버나 데이터베이스 설정도 필요 없습니다.

### AI 사회자를 쓰려면 (선택)
AI 사회자의 멘트와 AI 플레이어의 대화는 Anthropic API로 만듭니다.

- 방장이 대기실의 **AI 사회자 연결** 칸에 API 키를 붙여 넣으면 됩니다. 키는 [console.anthropic.com](https://console.anthropic.com)에서 발급합니다.
- 키는 방장의 브라우저에서 Anthropic 서버로만 전달됩니다. 다른 참가자에게는 보내지지 않고, 저장소 코드에도 들어 있지 않습니다. 저장소에 키를 직접 적어 넣지 마세요.
- 사용한 만큼 키 주인에게 비용이 청구됩니다. 기본 모델은 `claude-haiku-5-5`이고, 모델 이름 칸에서 바꿀 수 있습니다.
- 키가 없어도 게임은 됩니다. 사회자는 정해진 문구로 진행하고, AI 플레이어는 단순한 규칙으로 움직입니다.

## 2. 사용법

1. 접속해서 닉네임을 적고 **방 만들기**를 누릅니다. 4자리 방 코드가 만들어지고, 만든 사람이 방장이 됩니다.
2. 방장이 코드를 알려 주면, 참여자는 같은 주소의 메인 화면에서 닉네임과 코드를 입력하고 **입장**을 누릅니다.
3. 방장은 대기실에서 다음을 정하고 **게임 시작**을 누릅니다.
   - 마피아·경찰·의사 인원 (시민은 남은 인원으로 자동 계산)
   - AI 플레이어: 추가 안 함 / 추가, 추가하면 몇 명인지
   - AI가 하는 일: **대화·투표 참여** 또는 **인원 채우기만**
   - 낮 토론 시간: 30·60·90·120초
4. 전체 인원은 4~12명이어야 하고, 마피아는 전체의 절반 미만이어야 시작할 수 있습니다.

### AI 플레이어
- **대화·투표 참여**: AI가 낮 토론에서 말하고, 투표와 최후의 변론도 합니다.
- **인원 채우기만**: AI는 낮 대화와 모든 투표(지목, 찬반)에 참여하지 않고 머릿수만 채웁니다.
- 어느 쪽이든 AI는 자기 직업의 밤 능력을 씁니다. AI 표시가 붙어서 누가 AI인지는 모두 알 수 있습니다.

### 알아둘 점
- **방장이 탭을 닫거나 새로고침하면 방이 사라집니다.** 게임 중에는 방장이 이 탭을 열어 두세요. 다른 탭에 오래 가 있으면 진행이 느려질 수 있습니다.
- 참가자가 새로고침하면 메인 화면의 "이전 방으로 돌아가기"로 같은 방에 다시 들어올 수 있습니다. (같은 탭에서만)
- 직접 연결 방식이라 회사·학교처럼 엄격한 네트워크에서는 연결이 안 될 수 있습니다.
- 각 참가자에게는 본인이 볼 수 있는 정보만 전달됩니다. 다만 방장의 브라우저는 모든 정보를 갖고 있어서, 방장은 기술적으로 볼 수 있습니다. 친구끼리 믿고 하는 게임으로 쓰세요.

## 3. 규칙

### 직업
| 직업 | 능력 |
|---|---|
| 마피아 | 밤마다 한 명을 제거합니다. 마피아끼리 서로의 정체를 알고, 밤에 비밀 채팅을 할 수 있습니다. 여러 명이면 가장 많이 선택된 사람이 제거되고, 동수면 그중 무작위입니다. |
| 경찰 | 밤마다 한 명을 조사해 **마피아인지 시민인지**만 알아냅니다. 결과는 본인만 봅니다. |
| 의사 | 밤마다 한 명을 지목해 마피아의 공격에서 살립니다. 자기 자신도 지목할 수 있습니다. |
| 시민 | 능력은 없고, 토론과 투표로 마피아를 찾습니다. |

### 승리 조건
- **시민 팀**(시민·경찰·의사): 마피아를 모두 제거하면 승리합니다.
- **마피아 팀**: 살아있는 마피아 수가 나머지 생존자 수 이상이 되면 승리합니다.

### 세부 규칙
- 게임은 1일차 **밤**부터 시작합니다.
- 날이 밝으면 사회자는 **누가 죽었는지, 그 사람이 마피아였는지 아닌지만** 알려 줍니다. 의사가 살렸는지, 어떻게 죽었는지는 밝히지 않습니다. 아무도 안 죽었으면 그렇게만 말합니다.
- 처형된 사람도 마피아였는지 아닌지만 공개됩니다. 게임이 끝나면 모든 직업이 공개됩니다.
- **밤에 하는 선택은 모두 익명**입니다. 마피아끼리도 동료가 누구를 골랐는지 보이지 않고, "선택 완료 N/M명"만 보입니다.
- 투표에서 가장 많은 표를 받은 사람이 **최후의 변론**을 하고, 이어지는 **찬반 투표**에서 찬성이 반대보다 많으면 처형됩니다. 동수면 부결입니다.
- 최다 득표가 동수이거나 유효한 표가 없으면 아무도 처형되지 않고 밤으로 넘어갑니다.
- 찬반 투표는 지목된 본인을 뺀 생존자가 합니다. 낮 투표는 득표 수만 발표하고 누가 누구를 골랐는지는 공개하지 않습니다.
- 죽은 사람은 말할 수 없지만 사망자 채팅으로 대화하고, 모든 대화와 직업을 볼 수 있습니다. 살아있는 사람에게 힌트를 주면 안 됩니다.
- 밤에는 마피아만 마피아 채팅을 쓸 수 있고, 최후의 변론 중에는 지목된 사람만 말할 수 있습니다.

## 4. 진행 과정

1. **밤** (30초): 마피아는 제거할 사람, 경찰은 조사할 사람, 의사는 살릴 사람을 고릅니다. 필요한 사람이 모두 고르면 조금 일찍 끝납니다.
2. **새벽**: 사회자가 누가 죽었는지와 마피아였는지 아닌지만 알려 줍니다.
3. **낮 토론** (방장이 정한 시간): 자유롭게 대화하며 마피아를 추리합니다. AI 플레이어도 대화에 참여합니다(대화·투표 참여 모드). 방장은 "토론 끝내기"로 일찍 넘길 수 있습니다.
4. **투표** (20초): 처형하고 싶은 사람을 지목하거나 기권합니다.
5. **최후의 변론** (20초): 가장 많은 표를 받은 사람이 해명합니다.
6. **찬반 투표** (15초): 처형에 찬성할지 반대할지 정합니다.
7. **저녁**: 사회자가 결과를 알려 주고, 승패가 나지 않았으면 다음 밤으로 넘어갑니다.
8. 승패가 나면 모든 직업이 공개되고, 방장은 같은 방에서 다시 시작하거나 방을 닫을 수 있습니다.

## 5. 기술 메모
- 파일은 `index.html` 하나입니다. 외부 의존성은 PeerJS(unpkg CDN)와 Google Fonts뿐입니다.
- 방 코드는 PeerJS 공용 연결 서버에 `hanbam-mafia-코드` 이름으로 등록됩니다. 연결 서버가 일시적으로 불안정하면 방 만들기·입장이 실패할 수 있습니다.
- 게임 로직은 모두 방장의 브라우저에서 돌아가며, 참가자에게는 사람별로 걸러진 상태만 보냅니다.
